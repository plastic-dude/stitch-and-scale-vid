## Concept and distinctness

“Accessible” can describe one checked mode while being heard as a promise across every device, input, language, print surface, chart, zoom level, and assistive technology. The nearest prior angle is `readability-under-load`, which focuses on legibility under competing attention and conditions. `accessibility-state` changes the pain to a broad accessibility label being mistaken for coverage across modes and conditions. The hook becomes “Accessible is not one setting.” The visual metaphor changes from difficult reading conditions to a broad badge resolving into a condition matrix. The proof surface is `SURFACE / MODE / VIEWPORT-ZOOM / INPUT / LANGUAGE / AUDIO-CAPTIONS / EVIDENCE / LIMIT / STATUS`. The emotional turn is from making content easier to read to being honest about what was and was not checked. The final line is “Name the access mode before you call it accessible.” It does not recreate chart description, caption clearance, paper proof, acceptance criteria, or either imported blocked concept.
