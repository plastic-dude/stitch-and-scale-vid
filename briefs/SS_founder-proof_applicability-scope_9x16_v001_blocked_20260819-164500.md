## Concept and distinctness

Valid evidence can still be applied to the wrong subject, artifact, size, use, locale, or condition. The nearest prior angle is `assumption-register`, which focuses on an input or model assumption being mistaken for an observed fact. `applicability-scope` changes the pain to valid evidence being transferred outside the use or application it actually supports. The hook becomes “Valid is not applicable.” The visual metaphor changes from observed/assumed/derived layers to a valid result surrounded by an incomplete intended-use boundary. The proof surface is `INTENDED USE / SUBJECT / ARTIFACT / SIZE / METHOD / CONDITIONS / SCOPE / EVIDENCE / RESULT / LIMIT / STATUS`. The emotional turn is from exposing hidden inputs to preventing a correct result from being misapplied. The final line is “Name the intended use before you apply the result.” It does not recreate uncertainty, acceptance criteria, accessibility state, fit intent, context lock, or either imported blocked concept.
