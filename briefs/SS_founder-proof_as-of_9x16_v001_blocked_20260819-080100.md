## Research decision

Craft Yarn Council’s current designer guidance was assembled in response to pattern complaints, covers challenges across pattern production, and states that its guidelines do not replace individual company guidelines. GOV.UK content guidance emphasizes clear and helpful content, user needs, planning new or changed content, tone, and accessibility. Neither source proves a universal version-control protocol, live freshness state, current accuracy, or any Stitch & Scale revision surface.

The research changed the concept from generic version history into **currentness labeling without a freshness promise**. The film must not claim live sync, current accuracy, automatic version control, correction completion, or publication approval.

## Campaign assumption

No active human brief was present in the checked repository state. This run assumes founding-tester recruitment remains the working objective through the free demo and early-access cohort. The film invites designers to inspect one verified as-of, version, revision, or review-state surface; it does not promise that a visible document is current, synchronized, or approved.

## Dramatic engine

| Element | Director decision |
|---|---|
| Subject | A visible pattern note is treated as current simply because it is present. |
| Desire | To know which revision and review moment a note belongs to. |
| Obstacle | A document can remain visible after context, source, or review state changes. |
| Stakes | A maker may act on an older note while believing it represents the current state. |
| Change | The viewer moves from “I can see it” to “I can place it in time and revision.” |
| Contradiction | An as-of label improves orientation but does not prove correctness or freshness. |
| Escalation | Pattern card appears → `AS OF / REVISION / REVIEWED?` split → `CURRENT?` remains unanswered → current proof or blocker. |
| Final image | A note card beside `AS OF / REVISION / REVIEWED?` and an open `CURRENT?`. |

## Difference from prior concepts

The nearest prior angle is `source-note`, which concerns where a statement came from and whether it was rechecked. `as-of` changes the pain to **a visible note being treated as current merely because it is visible**; the hook to **“Visible is not the same as current.”**; the visual metaphor from source tabs to `AS OF / REVISION / REVIEWED?` cards with an unanswered `CURRENT?`; the proof surface from source-note/provenance/evidence status to a current version, as-of, revision, or review-state surface; the emotional turn from source humility to time-aware orientation; and the final line to **“Name the revision. Mark the moment.”**

It is distinct from `source-note` because it is about temporal placement rather than source class; from `correction-trace` because it is not a change narrative or correction ledger; from `offline-continuity` because it is not network state; from `decision-ledger` because it is not value classification; from `data-minimum` because it is not data-collection scope; and from `false-completion`, `release-gate-roster`, `size-boundary`, `material-notes`, `care-context`, `feedback-loop`, `support-boundary`, `brief-before-knit`, `sample-chain`, `measurement-moment`, `gauge-reality`, `technique-profile`, `permission-line`, `recovery-proof`, `event-window`, `evidence-over-output`, `inherited-thread`, `readability-under-load`, `chart-parity`, `equivalent-meaning`, `locale-drift`, and `reader-handoff` because the conflict is time placement versus present-tense certainty. It does not reopen, overwrite, rename, or consume the imported reservations.

## Treatment, visual grammar, and production bible

Open on an original fictional pattern card labeled `ILLUSTRATIVE — NOT PRODUCT UI` with a blank note such as `PATTERN NOTE / REVISION ?`. Three cards separate: `AS OF`, `REVISION`, and `REVIEWED?`. A fourth prompt reads `CURRENT?` with no answer. A green `CURRENT` badge, live-sync icon, and approval stamp are deliberately rejected. No real pattern text, correction, product version, user record, or date is shown.

The product insert is optional and blocked until a current, versioned, non-private proof capture verifies exact as-of, revision, version, last-reviewed, or review-state labels. If absent, retain `CURRENTNESS PROOF REQUIRED — NOT PRODUCT UI`. Any real pattern page, correction record, version label, publication state, or person requires source and rights review. David may appear only with authorization and must be described only as a developer whose late mother knitted; he is not a knitter, knitwear designer, pattern designer, or technical editor. Use one narrator family. Captions must not cover revision cards, proof, hands, or CTA. Review caption-on and caption-free cuts.
