## Concept and distinctness

A clean number or recommendation can be driven by an input choice that was never named. The nearest prior angle is `uncertainty-context`, which focuses on a precise number retaining uncertainty context. `assumption-register` changes the pain to an input or model assumption being mistaken for an observed fact. The hook becomes “Assumed is not observed.” The visual metaphor changes from a number surrounded by uncertainty to a clean result split into `OBSERVED / ASSUMED / DERIVED`. The proof surface is `OBSERVED / ASSUMED / DERIVED / SOURCE / SCOPE / DATE-VERSION / STATUS / NOTES`. The emotional turn is from tolerating uncertainty to exposing the input choice that created the result. The final line is “Name the assumption before you trust the result.” It does not recreate comparison basis, gauge reality, grading transparency, acceptance criteria, decision reversal, or either imported blocked concept.
