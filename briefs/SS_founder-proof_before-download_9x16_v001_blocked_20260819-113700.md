## Research decision

CYC’s Project Levels guidance describes general Basic, Easy, Intermediate, and Complex categories using stitches, shaping, colorwork, and techniques, but a level is not a full difficulty guarantee or complete pattern record.[202] The Ravelry pattern route redirected to login, so no marketplace metadata or competitor weakness was inferred.[203] Stitch & Scale’s contracts require readable metadata, measurements, technical fields, source/status labels, and distinct human evidence.[204] [205] [206] These sources support a pre-download context checklist, but do not prove Stitch & Scale operates such a surface.

## Difference from nearest prior angle

The nearest prior angle is `work-scope`, which focuses on the scope of the designer’s ask inside a workflow. `before-download` changes the pain to **whether a maker can decide before purchase or download using factual context**. The hook changes to **“Before the download, show the work.”** The visual metaphor changes from an internal scope card to **`BEFORE YOU START / LEVEL / MEASUREMENTS / GAUGE / MATERIALS / TECHNIQUES / FORMAT / LANGUAGE`**. The proof surface changes from an internal request boundary to a current pre-download context panel with source/date and status. The emotional turn changes from defining the task to giving the reader a fair, factual pause. The final line changes to **“Let the maker decide with the facts.”**

It is distinct from `fit-intent` because it is pre-download disclosure rather than intended garment fit; from `price-basis` because it is context rather than cost category; from `artifact-status` because it is reader-facing decision context rather than copy status; and from imported `false-completion` and `release-gate-roster` because it is not completion or evidence-roster accountability. Neither imported concept is reopened, renamed, overwritten, or approved.
