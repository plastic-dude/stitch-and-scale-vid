## Research decision

Craft Yarn Council says a person may measure a garment that fits the way they want and use it as a guide, while distinguishing actual body measurements, completed-garment measurements, and schematics. NIST defines traceability through an explicitly described, documented chain of calibrations or comparisons to specified reference standards, linking measured values and uncertainties. These sources support naming the reference and scope of a comparison, but they do not prove Stitch & Scale exposes reference metadata, comparison linking, or traceability.

## Difference from nearest prior angle

The nearest prior angle is `basis-label`, which focuses on whether a value is measured, estimated, planned, or derived. `comparison-frame` changes the pain to **which object or standard the value is being compared against and what scope the comparison has**. The hook changes to **“A comparison is only as clear as its reference.”** The visual metaphor changes from value-basis cards to **`REFERENCE / MEASURED / COMPARED / SCOPE`**. The proof surface changes from value-status/provenance to a current reference-object label, measured-versus-reference pair, comparison frame, source/target relationship, or scoped comparison record. The emotional turn changes from epistemic humility about a value’s basis to meaningful comparison through named reference and scope. The final line changes to **“Name the reference before you compare the result.”**

It is distinct from `basis-label` because it is the comparison frame rather than the value’s type; from `default-state` because it is not whether a value was chosen; from `context-lock` because it is not which record is active; from `fit-intent` because it is not body/garment/ease meaning; from `finish-state` because it is not object condition; and from imported `false-completion` and `release-gate-roster` because it is not completion or roster accountability. Neither imported concept is reopened, renamed, overwritten, or approved.
