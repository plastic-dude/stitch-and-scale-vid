## Research decision

NIST describes information quality through utility, integrity, and objectivity, with review appropriate to the nature and timeliness of information.[374] IBM distinguishes data reconciliation from validation and synchronization and describes comparison, discrepancy identification, resolution, validation, and audit logging as separate steps, with some discrepancies requiring manual contextual judgment.[375] Internal contracts preserve source/date, recorded-versus-derived values, provenance, uncertainty, export identity, and distinct human evidence gates.[380] Current platform and caption guidance supports a short vertical master with human-reviewed captions.[376] [377] [378] [379] None of this proves current Stitch & Scale conflict-state behavior.

## Concept and dramatic engine

| Engine element | Director decision |
|---|---|
| Subject | Two records with different values for the same item. |
| Desire | To keep both observations visible long enough for a bounded human decision. |
| Obstacle | A workflow may be tempted to silently overwrite one value or pick a winner without evidence. |
| Stakes | A hidden disagreement can contaminate a later measurement, grade, purchase, or record; no real defect or outcome is claimed. |
| Change | The fictional record adds source A/source B, observed time, scope, conflict type, evidence, decision, resolver, decided-at, status, and follow-up. |
| Contradiction | Recording disagreement is more honest than pretending the source is already settled. |
| Escalation | Source A ≠ Source B → conflict type → evidence → decision → resolver/time → unresolved/resolved status → follow-up. |
| Final image | `CONFLICT VISIBLE — SOURCE OF TRUTH NOT ASSUMED`. |

## Difference from nearest prior angle

The nearest prior angle is `value-state`, which separates blank, zero, not-applicable, invalid, derived, planned, and unverified values. `conflict-state` changes the pain to **two otherwise meaningful records disagreeing and the disagreement being silently collapsed before a human decision**. The hook changes to **“Two sources disagree. That is a state.”** The visual metaphor changes from value-status cards to two source cards connected by a red conflict line, followed by evidence, decision, resolver, and follow-up cards. The proof surface changes from a value-state field set to a source-comparison/conflict record. The emotional turn changes from null/zero humility to preserving disagreement long enough for a bounded human decision. The final line changes to **“Name the conflict before you choose the record.”**

It is distinct from `impact-scope` because it is not downstream propagation; from `comparison-frame` because it is not the reference object; from `decision-ledger` because it is not decision rationale generally; from `source-note` because it is not provenance alone; from `review-anchor` because it is not comment location/version; from `correction-trace` because it is not released errata; from `capture-freshness` because it is not proof-artifact currentness; and from `payment-state` because it is not money. It does not reopen or reuse `false-completion` or `release-gate-roster`.
