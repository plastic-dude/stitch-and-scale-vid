## Research decision

CYC explains rows, right-side/wrong-side labels, repeats, and instruction sequence.[213] Purl Soho’s tutorial describes provisional cast-on as keeping stitches live for later use, joining main yarn, checking for twist before joining in the round, removing temporary yarn, and later using live stitches for hems or closures.[214] Stitch & Scale’s contracts preserve construction, test knitting, technical editing, chart, schematic, and print review as separate human evidence.[215] [216] These sources support a route map, but do not prove Stitch & Scale parses or validates construction routes.

## Difference from nearest prior angle

The nearest prior angle is `direction-cue`, which focuses on which way a row travels. `construction-route` changes the pain to **which construction path the fabric follows, including flat work, joins, rounds, held live stitches, temporary yarn removal, and closure**. The hook changes to **“The next step is a route change.”** The visual metaphor changes from directional arrows to **`START / FLAT / TURN / JOIN / ROUND / LIVE / REMOVE / CLOSE`**. The proof surface changes from row traversal orientation to a current construction-route surface with source/date and status. The emotional turn changes from reading direction to seeing route transitions before the maker hands off or joins the fabric. The final line changes to **“Map the route before the fabric moves.”**

It is distinct from `repeat-scope` because it is construction topology rather than grouping; from `finish-state` because it is route transitions rather than object status; from `prerequisite-state` because it is a path map rather than a step prerequisite; and from imported `false-completion` and `release-gate-roster` because it is not completion or evidence-roster accountability. Neither imported concept is reopened, renamed, overwritten, or approved.
