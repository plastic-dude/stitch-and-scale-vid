## Research decision

NIST provides conversion factors for quantities expressed in different units and explains that factors and selected prefixes affect the resulting numerical magnitude.[404] Sister Mountain’s current grading workflow uses consistent units and a formula column to convert centimetres into inches.[405] Internal contracts preserve source/date, recorded-versus-derived values, measurement context, localization, export identity, and distinct human evidence gates.[410] Current platform and caption guidance supports a short vertical master with human-reviewed captions.[406] [407] [408] [409] None of this proves current Stitch & Scale conversion behavior.

## Difference from nearest prior angle

The nearest prior angle is `locale-number-format`, which focuses on how numbers are displayed for a locale. `conversion-trace` changes the pain to **a transformed number being mistaken for the original observation because the raw value, units, factor, rounding, or source disappear**. The hook changes to **“Converted is not observed.”** The visual metaphor changes from locale display cards to a raw-value card linked by a visible factor/rule arrow to a converted-value card, followed by rounding, source/date, and status cards. The proof surface changes from display conventions to raw/transformed lineage. The emotional turn changes from readable localization to measurement humility about what was observed versus calculated. The final line changes to **“Keep the original before you trust the conversion.”**

It is distinct from `rounding-rule` because it includes raw/transformed lineage; from `measurement-provenance` because it is not who/when measured; from `value-state` because it is not blank/zero/invalid semantics; from `translation-scope` because it is not language; from `locale-number-format` because it is not display convention; and from `exception-scope` because it is not a local override. It does not reopen or reuse `false-completion` or `release-gate-roster`.
