## Research-informed premise

Craft Yarn Council guidance shows that knitting instructions save space with abbreviations, repeat marks, “maintain pattern as established,” and “work same as left piece, reversing shaping.” The last instruction can leave a reader to find the earlier work, reverse it, preserve side and row context, and continue. [1] W3C cognitive guidance recommends clear headings, boundaries, regions, and cues that help a person restore context after distraction; it also warns against processes that rely on memory and notes that mobile or noisy situations can split attention. [2] These sources justify a general workflow lesson about reference targets and return cues. They do not prove any Stitch & Scale capability.

> **A pointer is not a path until the reader can name the target, the scope, and where to return.**
