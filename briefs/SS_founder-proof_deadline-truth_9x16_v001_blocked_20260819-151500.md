## Research decision

CYC identifies a workflow pitfall where a designer sends a garment to meet a deadline before writing the pattern and then writes from notes.[280] GOV.UK recommends explicit machine-readable date/time ordering and timezone offsets where relevant, with clarity around local time and midnight.[281] Stitch & Scale’s contracts keep design lifecycle, submissions, deadlines, notes, status history, source/date, local-first records, and interruption safety separate.[282] [283] These sources support a typed deadline checklist, but do not prove Stitch & Scale automates deadlines.

## Concept and dramatic engine

## Difference from nearest prior angle

The nearest prior angle is `change-notice`, which focuses on what changed and how to communicate a change. `deadline-truth` changes the pain to **whether a date is being mistaken for a commitment or outcome**. The hook changes to **“A date is not a promise.”** The visual metaphor changes from change fields to **`DATE TYPE / TARGET OR HARD / EVENT OR PUBLICATION / LOCAL TIME / UTC OFFSET / OWNER / SOURCE / STATUS / NOTES`**. The proof surface changes from a change record to a current deadline-context surface. The emotional turn changes from noticing a changed artifact to typing a date so its obligation and evidence are explicit. The final line changes to **“Type the date before you trust the deadline.”**

It is distinct from `context-lock` because it does not preserve project state; from `resume-point` because it does not recover an interrupted task; from `availability-status` because it does not date supply; from `change-notice` because it does not explain an artifact revision; and from imported `false-completion` and `release-gate-roster` because it is not completion or evidence-roster accountability. Neither imported concept is reopened, renamed, overwritten, or approved.
