## Concept and distinctness

One changed upstream measurement or rule can affect multiple downstream artifacts, but a downstream artifact may still look complete. The nearest prior angle is `tolerance-state`, which concerns an unexplained target/observed decision boundary. `dependency-state` changes the pain to stale downstream outputs after upstream change. The hook becomes “Changed upstream is not reviewed downstream.” The visual metaphor changes from target/observed bands to an upstream change rippling through dependent artifacts. The proof surface is `CHANGED INPUT / DEPENDENTS / LAST BUILT FROM / STALE? / RECHECKED? / OWNER / AFFECTED OUTPUT / RELEASE STATE`, explicitly illustrative until product proof exists. The emotional turn is from explainable measurement decision to bounded impact. The final line is “Name what changed before you trust what depends on it.” It does not recreate `authority-state`, `provenance-chain`, `version-lock`, `drift-state`, `supersession-state`, `reproducibility-state`, `conversion-trace`, `outcome-proof`, imported `false-completion`, or imported `release-gate-roster`.
