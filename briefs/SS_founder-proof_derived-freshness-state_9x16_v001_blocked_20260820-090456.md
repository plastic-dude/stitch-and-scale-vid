## Core creative distinction

The nearest prior is pass 246 `labor-visibility-state`. Pass 246 asked which human work categories disappear behind a finished-looking pattern output. Pass 247 asks whether a downstream value is still current after an upstream source changes.

| Dimension | Pass 246 `labor-visibility-state` | Pass 247 `derived-freshness-state` |
|---|---|---|
| Changed pain | Visibility gap: work categories disappear behind a finished-looking file. | Derived-value staleness: downstream values look complete after a source changes. |
| Hook | “A pattern file can look finished while the work is still invisible.” | “A changed source can leave a clean-looking value behind.” |
| Visual metaphor | Finished-file card unfolding into a work-category receipt. | Two-column source/derived card with a stopped dependency arrow. |
| Proof surface | Output, work category, evidence, owner, status, cost unknown, value not calculated. | Source, source version, derived value, depends on, last check, recompute status, reviewer, limit. |
| Emotional turn | Recognition without assigning a price. | False reassurance replaced by a small recalculation question. |
| Final line | “Name the work before you name the value.” | “Trace the source before you trust the result.” |

The angle is not a rename of `grading`, `gauge`, `derived-value`, `source-note`, `labor-visibility-state`, `revisitability-state`, `restore-boundary-state`, or any prior evidence-state concept. It is a source-to-derived freshness question, not a claim of automatic recalculation or grading approval.

## Dramatic engine before camera

**Subject:** A fictional two-column source/derived card for one pattern-project value.  
**Desire:** Know whether a visible downstream value still belongs to the current source.  
**Obstacle:** The source changes while the derived value remains visually clean and lacks a visible last-check or recomputation state.  
**Stakes:** A designer may review, publish, or carry forward a stale value; the video must not claim this has happened to a Stitch & Scale user.  
**Change:** Move from “the value is present” to “the dependency and last check are visible.”  
**Contradiction:** A clean number can be less trustworthy than an unresolved status.  
**Escalation:** The source card changes; the derived card does not; an arrow stops at `RECOMPUTE CHECK: UNRESOLVED`; the narrator names the human limit.  
**Final image:** `SOURCE VERSION` connected to `DERIVED VALUE`, with `LAST CHECK: UNRESOLVED`, `REVIEWER: UNASSIGNED`, and `ILLUSTRATIVE — NOT PRODUCT UI`.

## Treatment

Open on a clean desk with a bold left card reading `SOURCE: GAUGE / BODY MEASUREMENT / EASE`. A right card reads `DERIVED: STITCHES / ROWS / YARDAGE / SCHEMATIC`. The narrator says, “A changed source can leave a clean-looking value behind.” A pencil changes only the source card’s label from `SOURCE VERSION A` to `SOURCE VERSION B`; the derived card stays still. A dependency arrow is drawn and stops at `RECOMPUTE CHECK: UNRESOLVED`. The card adds `LAST CHECK`, `REVIEWER`, and `LIMIT`. The narrator separates this question from technical editing, physical print review, chart readability, schematic scale, and test knitting. The founder turns the paper away and says he will not pretend this is the app. The final card asks founding testers what the current product can actually show about source and derived values.

## Visual grammar and production bible

Use one narrator family, one tabletop, one paper system, one charcoal/cream/ink-blue palette, and a strict type hierarchy. The only readable words are the fictional labels listed in this brief, with the fixed footer `ILLUSTRATIVE — NOT PRODUCT UI`. Do not render real stitch counts, row counts, yardage, body measurements, formulas, chart symbols, schematic measurements, customer records, or UI controls. Generated text is not UI truth. Any future product number, label, warning, or control must come from a current approved capture.

The primary location is a quiet desk with no private documents. Use one locked overhead camera and one 45-degree macro angle. Keep both columns within a high-contrast central area. Use a source-card change, a stopped pencil arrow, and an unresolved status as the visual rhythm. No digital glitch, fake loading, fake save, fake database, or effect may imply product behavior. The arrangement is source card at left, derived card at right, dependency arrow between them, and reviewer/limit fields below.
