## Concept and distinctness

A record can look stable while the underlying measure or context drifts. The nearest prior angle is `outcome-proof`, which separates action completion from an observed intended effect. `drift-state` changes the pain to a state or measure being treated as current and stable even though its baseline, time window, comparison context, or review cadence is missing. The hook becomes “Stable is not current.” The visual metaphor changes from an after-action outcome card to a time-bounded status card with a stale review window. The proof surface is `BASELINE / CURRENT OBSERVATION / OBSERVED CHANGE / DRIFT SIGNAL / REVIEW PERIOD / COMPARISON CONTEXT / NEXT REVIEW / STATUS`. The emotional turn is from separating activity from effect to questioning currentness. The final line is “Name the review period before you call it stable.” It does not recreate outcome proof, response state, risk trigger, failure mode, evidence type, evidence coverage, provenance chain, acceptance criteria, false completion, release roster, or a human release checklist.
