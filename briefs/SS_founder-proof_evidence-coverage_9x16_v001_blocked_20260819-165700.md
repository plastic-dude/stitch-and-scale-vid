## Concept and distinctness

Evidence can exist while a claim remains unsupported, mismatched, or outside the evidence’s scope. The nearest prior angle is `provenance-chain`, which focuses on the path from source through activities and responsibility to one result. `evidence-coverage` changes the pain to a set of claims or requirements being mistaken as covered because some evidence exists, even when the evidence is mismatched or incomplete for individual claims. The hook becomes “Evidence is not coverage.” The visual metaphor changes from a bidirectional source-to-result chain to a claim/evidence matrix with `COVERED / PARTIAL / GAP`. The proof surface is `CLAIM / REQUIREMENT / EVIDENCE ITEM / COVERAGE TYPE / SCOPE / OWNER / GAP / STATUS`. The emotional turn is from accountability for how a result was made to seeing the uncovered claim before publication or decision. The final line is “Map the evidence before you call it covered.” It does not recreate provenance chain, acceptance criteria, false completion, release roster, applicability scope, assumption register, or a human release checklist.
