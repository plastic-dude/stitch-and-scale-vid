## Research-informed distinction

Pass 205 kept a result attached to scope, uncertainty, limitations, and cannot-conclude boundaries. Pass 206 adds the source-lineage boundary: the record should identify the entities, activities, derivations, responsible agents, and source documents that produced or influenced the result, while showing when the chain is incomplete. W3C PROV-DM describes provenance as information about entities, activities, and people involved in producing, influencing, or delivering a thing and says it can support quality, reliability, or trustworthiness assessments. The GOV.UK Data Quality Framework covers source, lifecycle, metadata, documentation, and communication. W3C’s WCAG-EM Report Tool records structured findings but does not perform automated checks and requires experienced evaluators. Craft Yarn Council keeps instructions, gauge, and human activities distinct. [1] [2] [3] [4]

> **A source is a starting point. The result needs a visible trail.**

These sources inform general workflow education only. They do not establish that Stitch & Scale currently records provenance, tracks derivation, assigns responsibility, validates source sufficiency, or automatically detects broken source chains.

## Nearest prior and concept difference

| Element | Pass 205 `result-boundary-state` | Pass 206 `evidence-lineage-state` |
|---|---|---|
| Primary pain | A criteria-fit result is reused outside its tested scope because limitations and cannot-conclude boundaries are detached or hidden | A result looks supported because a source exists, while the derivation, activity, responsibility, or currentness of the source trail is unclear |
| Hook | “A result without its boundary invites a use it never tested.” | “A source is a starting point. The result needs a visible trail.” |
| Visual metaphor | Bright tested frame with grey `NOT EVALUATED` area and `CANNOT_CONCLUDE` line | Chain of source, activity, derivation, agent, and result cards with one dashed `NOT VERIFIED` link |
| Proof surface | `BOUNDARY A-001 / EVIDENCE_CHAIN / INTENDED_USE / SAMPLE_OR_SCOPE / CHECK_PERFORMED / FINDING / UNCERTAINTY_OR_LIMITS / CANNOT_CONCLUDE / FIT_SCOPE / DISPOSITION` | `LINEAGE A-001 / SOURCE_ENTITY / SOURCE_VERSION_OR_DATE / ACTIVITY_OR_TRANSFORM / DERIVATION_LINK / RESPONSIBLE_AGENT / RESULT / SOURCE_SUFFICIENCY / CHAIN_STATUS / DISPOSITION` |
| Emotional turn | Trust through honest boundaries | Cautious confidence: show the trail before asking anyone to trust the destination |
| Final line | “Keep the result with its scope, its limits, and what it cannot prove.” | “Show the source, the work, the person responsible, and the link to the result.” |

## Dramatic engine

| Engine element | Design |
|---|---|
| Subject | A chain of neutral cards connecting source, activity, derivation, responsible agent, and result. |
| Desire | Let a useful result be inspectable rather than asking the audience to trust a citation alone. |
| Obstacle | The source exists, but version, activity, derivation, responsibility, currentness, and sufficiency are incomplete. |
| Stakes | A named source can create false confidence when the chain between source and result is missing; the film must not claim a real incident or product outcome. |
| Change | The chain becomes visible, one link remains dashed and unverified, and the result stays held rather than receiving a trust stamp. |
| Contradiction | A source can be genuine while its connection to this result remains unproven. |
| Escalation | `SOURCE_ENTITY` → version/date requested → `ACTIVITY_OR_TRANSFORM` named → `DERIVATION_LINK` drawn → responsible agent exposed → result linked → source sufficiency tested → chain status held. |
| Final image | `LINEAGE A-001 / SOURCE_ENTITY: ILLUSTRATIVE INPUT / SOURCE_VERSION_OR_DATE: NOT SUPPLIED / ACTIVITY_OR_TRANSFORM: EXAMPLE CHECK / DERIVATION_LINK: NOT VERIFIED / RESPONSIBLE_AGENT: UNCONFIRMED / RESULT: EXAMPLE ONLY / SOURCE_SUFFICIENCY: PENDING / CHAIN_STATUS: INCOMPLETE / DISPOSITION: HOLD`. |

## Treatment and beats

The film opens on a neutral tabletop. A result card sits alone with a small source note. The source note is not allowed to become a trust stamp. A chain begins: source entity, source version or date, activity or transform, derivation link, responsible agent, and result.

The source and activity are visible, but one derivation link is dashed and labeled `NOT VERIFIED`. The responsible agent and source sufficiency remain incomplete. The final chain status is `INCOMPLETE`, and the result stays held until current evidence and accountable review exist.
