## Concept and distinctness

A rich evidence item can still answer the wrong question. The nearest prior angle is `evidence-coverage`, which maps multiple claims or requirements to evidence and exposes `COVERED / PARTIAL / GAP` cells. `evidence-type` changes the pain to a single evidence item being treated as interchangeable with a different kind of evidence, even when the questions differ. The hook becomes “Evidence is not interchangeable.” The visual metaphor changes from a claim/evidence coverage matrix to paired question/evidence-type cards with `SUPPORTS / DOES NOT SUPPORT`. The proof surface is `QUESTION / EVIDENCE TYPE / SUPPORTS / DOES NOT SUPPORT / CONDITIONS / STATUS`. The emotional turn is from seeing an uncovered claim to respecting the limits of each evidence form. The final line is “Match the evidence to the question.” It does not recreate evidence coverage, provenance chain, applicability scope, acceptance criteria, false completion, release roster, or a human release checklist.
