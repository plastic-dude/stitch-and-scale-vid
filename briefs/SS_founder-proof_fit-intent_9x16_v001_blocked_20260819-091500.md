## Campaign assumption

No active human brief was present in the refreshed repository. This run assumes founding-tester recruitment through the free demo and early-access cohort remains the campaign objective. The film is a year-round story about measurement meaning, not a fit guarantee or size recommendation. It invites designers to inspect one current sizing table, finished-measurement table, ease/fit note, body-versus-garment label, schematic relationship, or size-selection explanation if proof is supplied; it does not promise that Stitch & Scale provides any of those behaviors.

## Research decision

The Craft Yarn Council distinguishes actual body measurements from completed-garment information and schematics, describes negative, zero, and positive ease, and says users should review all sizing information before beginning. GOV.UK table guidance recommends descriptive unique headings, simpler tables, clear placement of important information, and explicit `no data` or `not applicable` labels. These sources do not prove Stitch & Scale exposes ease, finished measurements, fit notes, or automatic size guidance.

## Difference from nearest prior angle

The nearest prior angle is `size-boundary`, which focuses on what supported size range or boundary is available. `fit-intent` changes the pain to **whether the number refers to the body, the finished garment, the difference between them, or an intended fit**. The hook changes to **“A size number is not a fit instruction.”** The visual metaphor changes from a boundary warning to **`BODY / FINISHED GARMENT / EASE / FIT NOTE`**. The proof surface changes from size eligibility/boundary to a current sizing table, finished-measurement table, ease/fit note, body-versus-garment label, schematic relationship, or size-selection explanation. The emotional turn changes from knowing the available boundary to choosing with context, without a fit guarantee. The final line changes to **“Name the measurement before you name the size.”**

It is distinct from `measurement-moment` because it is not when a measurement was captured; from `size-boundary` because it is not size-range support; from `basis-label` because it is not provenance or certainty of a number; from `chart-parity` because it is not chart/instruction agreement; from `schematic-scale` because it is not physical readability; from `artifact-status` because it is not copy identity; and from imported `false-completion` and `release-gate-roster` because it is not completion or roster accountability. Neither imported concept is reopened, renamed, overwritten, or approved.
