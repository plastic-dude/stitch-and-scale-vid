## Research decision

CYC describes gauge as stitches and rows per inch, explains that maker tension differs, recommends a sample swatch, and notes that swatch dimensions/context can vary, including working in rounds.[244] CYC’s reading guidance recommends using the yarn, needles, and pattern stitch called for and re-swatching after a tool-size change when the swatch differs.[245] Stitch & Scale’s contracts keep gauge, swatch, tool/yarn, care/blocking, measurement, grading, technical editing, print/chart review, and test knitting separate.[246] [247] These sources support a stateful gauge record, but do not prove Stitch & Scale measures or validates one.

## Difference from nearest prior angle

The nearest prior angle is `count-check`, which focuses on whether a numeric result matches. `gauge-state` changes the pain to **whether a gauge number retains the physical state and context in which it was measured**. The hook changes to **“Gauge is a state, not just a number.”** The visual metaphor changes from a count result to **`STITCH / ROW / STITCH PATTERN / YARN / TOOL / WINDOW / PRE-WASH / POST-WASH / BLOCKED / UNBLOCKED / SAMPLE / STATUS`**. The proof surface changes from a count check to a current gauge-record surface. The emotional turn changes from confirming a number to preserving its physical context without a measurement or fit promise. The final line changes to **“Record the swatch state, not just the gauge.”**

It is distinct from `tool-context` because it preserves the state of a measured swatch rather than naming a tool; from `care-path` because it does not give wash instructions; from `substitution-basis` because it does not compare yarns; from `measurement-provenance` because it captures physical swatch context rather than number lineage; and from imported `false-completion` and `release-gate-roster` because it is not completion or evidence-roster accountability. Neither imported concept is reopened, renamed, overwritten, or approved.
