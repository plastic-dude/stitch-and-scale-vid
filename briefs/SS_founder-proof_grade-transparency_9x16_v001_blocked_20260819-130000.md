## Research decision

CYC provides body-size charts, fit/ease guidance, garment context, and guidance to list measurements for each size and identify the size made.[237] [238] Sister Mountain presents a structured spreadsheet workflow for choosing sizes, adding body measurements, recording ease, calculating stitch/row counts, and keeping the layout clear; it also distinguishes displayed decimals from underlying data.[239] Stitch & Scale’s contracts keep grading, canonical outputs, rounding, exceptions, source/version, technical editing, print/chart review, and test knitting separate.[240] [241] These sources support a grade-audit checklist, but do not prove Stitch & Scale exposes grading math or validates every grade.

## Concept and dramatic engine

| Engine element | Director decision |
|---|---|
| Subject | A fictional grade-audit card shows why one size differs from another. |
| Desire | To inspect the path from base size to each graded size. |
| Obstacle | A finished size table can show outputs without showing increment, rule, exception, or override. |
| Stakes | The designer may treat a mysterious output as a trustworthy grade; no accuracy outcome is claimed. |
| Change | The fictional card exposes grade inputs, rules, exceptions, and review status. |
| Contradiction | A visible rule is more inspectable, but not automatically correct. |
| Escalation | Base → size/increment → rule/rounding → exception/override → review/source/version → proof or blocker. |
| Final image | `GRADE PATH VISIBLE — REVIEW OPEN`. |

## Difference from nearest prior angle

The nearest prior angle is `rounding-rule`, which focuses on which rule changed a result at the rounding step. `grade-transparency` changes the pain to **why a size differs from another size across the whole grade path**. The hook changes to **“A size changed. Show the rule.”** The visual metaphor changes from one result’s rule to **`BASE / SIZE / INCREMENT / RULE / ROUNDING / EXCEPTION / OVERRIDE / REVIEW / SOURCE / VERSION`**. The proof surface changes from a rounding explanation to a current grade-audit surface. The emotional turn changes from understanding one output to seeing the grade path without claiming it is correct. The final line changes to **“Show the grade, not just the size.”**

It is distinct from `mod-boundary` because it examines size-to-size logic rather than where a modification stops; from `size-number` because it explains grade movement rather than a size label; from `measurement-provenance` because it is a grade path rather than a number’s origin; and from imported `false-completion` and `release-gate-roster` because it is not completion or evidence-roster accountability. Neither imported concept is reopened, renamed, overwritten, or approved.
