## Concept and distinctness

A tap can be real while the intended target, scope, consequence, and reversal path remain unclear. The nearest prior angle is `resume-state`, which concerns return state after interruption. `intent-state` changes the pain to unverified action scope before a consequential change, deletion, or export. The hook becomes “Tapped is not intended.” The visual metaphor changes from restored/reconstructed return paths to a tap fanning into target/scope/consequence/reversal paths. The proof surface is `ACTION / TARGET / SCOPE / CONSEQUENCE / REVERSIBLE? / REVIEWED / CONFIRMED / RESULT`, explicitly illustrative until product proof exists. The emotional turn is from accidental-action anxiety to explicit intent. The final line is “Name what will change before you confirm.” It does not recreate `consent-state`, `commit-state`, `selection-state`, `response-state`, `acceptance-criteria`, `resume-state`, `backup-state`, imported `false-completion`, or imported `release-gate-roster`.
