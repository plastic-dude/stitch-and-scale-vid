## Research decision

Unicode CLDR explains that number patterns use decimal and grouping placeholders whose visible symbols are replaced by locale equivalents; the same numeric value can therefore appear with different separators.[173] GOV.UK guidance separates translation need from content structure and warns against placing translated text beside English in ways that create assistive-technology problems.[174] Craft Yarn Council presents actual body measurements in both inches and centimeters and says fit and length charts are guidelines, not universal outcomes.[175] These sources support explicit locale, separator, unit, language, and measurement-context cues, but they do not prove Stitch & Scale performs locale-aware formatting or conversion.

## Difference from nearest prior angle

The nearest prior angle is `rounding-rule`, which focuses on the rule used to round a result. `locale-number-format` changes the pain to **whether a maker can interpret the same measurement when decimal/grouping punctuation, unit, language, and body-versus-garment context change**. The hook changes to **“The number did not change. The punctuation did.”** The visual metaphor changes from a rounding decision to **`LOCALE / SEPARATOR / UNIT / CONTEXT`**. The proof surface changes from a rounding rule to a current locale-aware number/unit/context display or export. The emotional turn changes from knowing a rule to trusting an interpreted value without conversion certainty. The final line changes to **“Name the locale before trusting the number.”**

It is distinct from `basis-label` because it is locale and representation context rather than numeric provenance; from `size-number` because it is punctuation, unit, language, and measurement context rather than size identity; from `measure-point` because it is interpretation across formats rather than measurement boundaries; from `comparison-frame` because it is locale transition rather than baseline comparison; and from imported `false-completion` and `release-gate-roster` because it is not completion or evidence-roster accountability. Neither imported concept is reopened, renamed, overwritten, or approved.

## Treatment and production bible

Open on a neutral tabletop with an original abstract measurement card marked `ILLUSTRATIVE — NOT PRODUCT UI`. Use a fictional value such as `12,5` only when its illustrative status is unmistakable; do not present it as a product output or a real customer measurement. A second card reads `LOCALE`, a third `SEPARATOR`, a fourth `UNIT`, and a fifth `CONTEXT`. Context choices are `BODY` and `GARMENT`, not a claimed product control. The final card reads `LOCALE VISIBLE — VALUE REVIEWED`.

A real Stitch & Scale locale switch, locale-aware number surface, unit display, or export may replace the fictional card only if a current, approved, non-private capture or proof-registry entry verifies the exact surface, labels, product version/date, and rights to show it. If proof is absent, retain the blocker card and disclaimer. No automatic conversion, translation, localization, silent-fallback prevention, or export-correctness claim is permitted.

Use one narrator family. David may appear only with authorization and remains described as a developer whose late mother knitted; he is not a knitter, knitwear designer, pattern designer, or technical editor. Captions must not cover number cards, separators, units, context labels, proof, tables, buttons, menus, logos, or CTA. Review caption-on and caption-free versions. Generated text remains illustrative and cannot substitute for current product proof.
