## Campaign assumption

No active human brief was present in the refreshed repository. This run assumes founding-tester recruitment through the free demo and early-access cohort remains the campaign objective. The film is a year-round story about measurement landmarks and direction, not guided-capture, camera-measurement, or automatic-fit promise. ## Research decision

Craft Yarn Council gives explicit landmarks and instructions for chest/bust, neck-to-wrist, shoulder, arm, waist, hip, hand, and foot measures. NIST emphasizes a documented measurement process and a defined measurement quantity rather than an unqualified result. These sources support explicit landmarks and direction, but they do not prove Stitch & Scale provides measurement-point diagrams, guided capture, camera measurement, or landmark validation.

## Concept and dramatic engine

| Engine element | Director decision |
|---|---|
| Subject | A measurement label is about to receive a value without stating where the line begins or ends. |
| Desire | To record a measurement another person can interpret consistently. |
| Obstacle | The same label can describe different landmarks, posture, direction, or object locations. |
| Stakes | A designer may compare unlike quantities or carry an ambiguous value forward; no actual product outcome is claimed. |
| Change | The fictional card names the quantity, from/to landmarks, method, and unit. |
| Contradiction | A precise number can still be ambiguous when the landmarks are hidden. |
| Escalation | `42` appears → `FROM / TO` enters → `HOW` and `UNIT` are added → human review. |
| Final image | `LANDMARKS NAMED — MEASUREMENT BOUNDED`. |

## Difference from nearest prior angle

The nearest prior angle is `measurement-moment`, which focuses on when a measurement is captured and whether a state remains legible. `measure-point` changes the pain to **the landmark and direction of the quantity itself**. The hook changes to **“A label is not a landmark.”** The visual metaphor changes from timing/state cards to **`WHAT / FROM / TO / HOW / UNIT`**. The proof surface changes from a measurement timestamp or capture-state surface to a measurement-point diagram, landmark instruction, from/to label, measurement direction, body/garment location note, or guided-capture surface. The emotional turn changes from temporal context to reproducible human measurement through explicit landmarks. The final line changes to **“Name the points before you trust the number.”**

It is distinct from `comparison-frame` because it is the definition of the measurement itself rather than the reference object used afterward; from `fit-intent` because it is landmark/direction rather than body/garment/ease meaning; from `context-lock` because it is not which record is active; from `finish-state` because it is not object condition; and from imported `false-completion` and `release-gate-roster` because it is not completion or roster accountability. Neither imported concept is reopened, renamed, overwritten, or approved.
