## Concept and distinctness

A citation points to an origin; it does not by itself show extraction, transformation, responsibility, version, review, or how the result was derived. The nearest prior angle is `capture-freshness`, which focuses on a screenshot’s date, version, scope, and review time not being a warranty of current proof. `provenance-chain` changes the pain to a source or origin being mistaken for a complete path from source through activity and responsibility to result. The hook becomes “A source is not a chain.” The visual metaphor changes from a dated capture with scope metadata to a bidirectional chain: `SOURCE → INPUT/EXTRACTION → ACTIVITY/TRANSFORMATION → AGENT/TOOL → VERSION-DATE → OUTPUT → REVIEWER`. The proof surface is `SOURCE / INPUT / ACTIVITY / TRANSFORMATION / AGENT-TOOL / VERSION-DATE / OUTPUT / REVIEWER / STATUS / LIMIT`. The emotional turn is from evidence humility about a capture to accountability for how a result was made. The final line is “Show how the source became the result.” It does not recreate source notes, converted status, decision ledgers, applicability scope, assumption register, or either imported blocked concept.
