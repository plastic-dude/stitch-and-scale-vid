## Treatment

The film opens with an original request card reading `REVIEW SWATCH + CHART / SENT`. A hand places it in a tray labeled only `INBOX`. The narrator asks who answers. No one moves the card. A second role card arrives and cannot tell whether the request is waiting, ignored, blocked, or already handled.

The request card is rebuilt with a request identity, artifact, gate, requested time, owner, channel, expected response, current status, decision/reason, next action, and closure. The status remains `WAITING`, not green completion. The final card says `REVIEW SWATCH / OWNER: HUMAN REVIEW / RESPONSE: BY 16:00 / NEXT: REVIEW SWATCH / CLOSED: PENDING`. If the request is declined, a reason and safe next action would replace the blank closure; no refusal or approval is fabricated.
