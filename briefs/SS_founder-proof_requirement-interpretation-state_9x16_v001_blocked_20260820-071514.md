## Research-informed premise

Craft Yarn Council’s current designer-pitfalls guidance identifies ambiguous or incomplete pattern communication failures: unexplained abbreviations, missing repeats, omitted row or stitch counts, absent right-side/wrong-side indications, incomplete materials, instructions written from memory, missing charts, missing schematics, and schematics not drawn to scale. [1] Its project guidance asks for explicit yarn, quantities, units, measurements, skill level, direction, totals, finishing, charts, and schematic context. [2] Knitty’s current June 17, 2026 submission guide likewise separates pattern notes, unusual abbreviations, written instructions, charts, schematics, images, rights, technical editing, and test knitting. [3]

Digital.gov’s current plain-language guide frames writing, design, and testing for a specific audience. [4] W3C WCAG 2.1 and Section 508 guidance support clear labels, instructions, text alternatives, error descriptions, correction suggestions, preserved relationships, and human evaluation, while warning that conformance does not address every user need. [5] [6] These sources support a bounded interpretation principle, not a comprehension guarantee or product capability claim.

## Treatment, beats, and visual grammar

Open on a neutral tabletop with a fictional card marked `DO THIS NEXT` and `ILLUSTRATIVE — NOT PRODUCT UI`. A hand turns it and reveals two plausible readings, each abstract and unbranded. Context cards enter: `FOR WHOM?`, `WHICH SIZE?`, `WHICH UNIT?`, `AT WHICH STAGE?`, `SHOW AN EXAMPLE`, `ASK BEFORE ACTING`. The final card refuses a green approval state and reads `INTERPRETATION: UNVERIFIED / HUMAN CHECK REQUIRED`.

| Time | Beat | Image and action | Spoken idea | Evidence status |
|---:|---|---|---|---|
| 0–5s | Bare instruction | `DO THIS NEXT` card; disclaimer visible. | “The clearest-looking instruction may still be missing its context.” | General principle; illustrative prop. |
| 5–11s | Split reading | Card separates into `READING A` and `READING B`. | “Two people can read the same line and prepare for different work.” | Process framing; no outcome claim. |
| 11–19s | Audience and stage | Cards: `FOR WHOM?` / `AT WHICH STAGE?`. | “Who is this for—and where are they in the project?” | Context question. |
| 19–27s | Size and unit | Cards: `WHICH SIZE?` / `WHICH UNIT?` / `RIGHT SIDE?`. | “Which size, which unit, which side, which repeat?” | Craft-pattern examples from [1]–[3]. |
| 27–34s | Example and question | `SHOW AN EXAMPLE` / `OPEN QUESTION` cards. | “If the action can change, show an example and leave a question open.” | Plain-language and form guidance. |
| 34–40s | Human gate | `TECH EDITING` / `PRINT REVIEW` / `CHART READABILITY` / `SCHEMATIC SCALE` / `TEST KNITTING`. | “That context helps. It does not replace technical editing or test knitting.” | Separate human gates. |
| 40–45s | Honest ending | `INTERPRETATION: UNVERIFIED` / `HUMAN CHECK REQUIRED`. | “Show the context before you ask for the action.” | Blocked; conditional next action. |

Use one neutral tabletop, diffuse side light, locked overhead and 45-degree inserts, and high-contrast original cards. Do not use real pattern text, charts, schematics, customer/tester data, publication logos, private instructions, or current UI. Do not use generated imagery for exact technical instructions, charts, schematics, or numeric fields. David may be voice-only or appear in a neutral developer frame; he must not perform knitting.
