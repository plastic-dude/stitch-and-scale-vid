## Concept and distinctness

A response can be planned without being authorized, authorized without being started, started without being complete, and complete without being verified. The nearest prior angle is `risk-trigger`, which binds a warning to an observable trigger and response action. `response-state` changes the pain to a planned response being treated as completed or verified without a recorded transition and evidence. The hook becomes “A plan is not an action.” The visual metaphor changes from a warning-to-action bridge to a response-state timeline. The proof surface is `PLAN / AUTHORIZATION / STARTED AT / COMPLETED AT / VERIFIED BY / VERIFICATION EVIDENCE / STATUS`. The emotional turn is from making response conditions explicit to distinguishing action lifecycle states. The final line is “Name the state before you call it done.” It does not recreate risk trigger, failure mode, evidence type, evidence coverage, provenance chain, acceptance criteria, false completion, release roster, or a human release checklist.
