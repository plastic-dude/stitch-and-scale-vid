## Research decision

CYC defines a schematic as a visual rendering with relevant measurements, an overview of size and shape, a fit reference, and a template for modifications; it recommends reviewing the schematic before starting.[274] W3C says complex diagrams may require a short description plus a long textual representation of essential information.[275] Stitch & Scale’s contracts keep schematic scale, chart readability, physical print review, technical editing, equivalent text, export, and test knitting separate.[276] [277] These sources support a schematic-context checklist, but do not prove Stitch & Scale renders or validates schematics.

## Difference from nearest prior angle

The nearest prior angle is `chart-description`, which focuses on describing a chart or visual sequence. `schematic-scale` changes the pain to **whether a line drawing is being trusted as a scale or measurement promise**. The hook changes to **“A drawing can show shape without being to scale.”** The visual metaphor changes from chart-description fields to **`GARMENT PART / VIEW / MEASUREMENT LABELS / UNITS / ORIENTATION / SCALE STATUS / REFERENCE STATUS / SOURCE / DATE / REVIEW`**. The proof surface changes from chart-description evidence to a current schematic-context surface. The emotional turn changes from describing a visual to making its measurement and scale status explicit. The final line changes to **“Label the drawing before you measure from it.”**

It is distinct from `measure-point` because it does not locate a measurement on a garment; from `measurement-provenance` because it does not trace where a number came from; from `export-portability` because it does not center file readers; from `sample-context` because it does not interpret a photographed sample; and from imported `false-completion` and `release-gate-roster` because it is not completion or evidence-roster accountability. Neither imported concept is reopened, renamed, overwritten, or approved.

## Caption map and audio plan

Use one narrator family with close, dry narration. Sound motif: a pencil line on `GARMENT PART / VIEW`, a soft ruler tap on `MEASUREMENT LABELS / UNITS`, a turn-page cue on `ORIENTATION / SCALE STATUS`, and a held silence before `REFERENCE STATUS / REVIEW`. No geometry-certainty swell, fit-guarantee cue, or print-perfect bed. Check for voice drift, doubled words, overlaps, accent changes, inconsistent mic distance, and room-tone jumps.

Captions are narration-verbatim, sentence by sentence, inside a declared safe zone that never covers diagrams, measurement labels, units, numbers, proof, tables, or CTA. Keep one schematic-context family on screen at a time for mobile reading. Retain caption-on and caption-free review masters. Automatic captions are not accepted as final. If a real complex image is ever shown, a deliberate equivalent-text and long description review remains required; no product accessibility claim is implied.
