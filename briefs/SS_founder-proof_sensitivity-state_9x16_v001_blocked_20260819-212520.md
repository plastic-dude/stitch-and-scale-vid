## Concept, distinctness, and research boundary

A small input movement can create a large downstream change. The nearest prior angle is `tolerance-state`, which asks whether a value is within a prescribed range. `sensitivity-state` asks what the output did when the input moved: perturbation, output delta, sensitivity, range, threshold, review, and decision. Hook: “Stable is not insensitive.” Fictional proof surface: `INPUT / PERTURBATION / OUTPUT DELTA / SENSITIVITY / RANGE / THRESHOLD / REVIEWED / DECISION`. Emotional turn: “The number barely moved” becomes “What changed downstream?” Final line: “Name what moved when the input moved.” Distinct from `dependency-state`, `calibration-state`, `reproducibility-state`, `context-state`, and `fitness-state`.

NIST’s law of propagation of uncertainty models an output as a function of inputs and includes sensitivity coefficients, input uncertainties, and covariance. Craft Yarn Council explains how gauge and personal tension affect finished size and recommends swatching and correction. These sources support workflow education only; they do not prove that Stitch & Scale currently computes sensitivity, robustness, output deltas, or grading stability.
