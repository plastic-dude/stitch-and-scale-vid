## Research decision

CYC notes that number/letter sizing varies by company, recommends package millimeter sizing, and says to compare a gauge swatch with the pattern gauge.[208] Tin Can Knits distinguishes suggested needle size, type, and length from gauge and notions, and says the maker uses the size needed to achieve design gauge.[209] Stitch & Scale’s contracts keep tools, notions, gauge, technical editing, and print/chart review separate.[210] [211] These sources support a tool-context checklist, but do not prove Stitch & Scale recommends tools or supplies complete materials metadata.

## Difference from nearest prior angle

The nearest prior angle is `before-download`, which focuses on broad factual context before a pattern download. `tool-context` changes the pain to **whether a needle number is being mistaken for a complete tool requirement during preparation**. The hook changes to **“A needle number is not a materials list.”** The visual metaphor changes from a pre-download context panel to **`SIZE / TYPE / LENGTH / CABLE / NUMBER / TECHNIQUE / NOTIONS / GAUGE`**. The proof surface changes from broad context metadata to a current tools/materials surface with **`SUGGESTED / REQUIRED / VERIFIED`** status. The emotional turn changes from fair pre-download disclosure to tool clarity before the first stitch. The final line changes to **“Name the tool before you start the stitch.”**

It is distinct from `substitution-basis` because it is tool context rather than yarn replacement; from `prerequisite-state` because it is a materials-definition surface rather than step readiness; from `before-download` because it narrows to tool completeness; and from imported `false-completion` and `release-gate-roster` because it is not completion or evidence-roster accountability. Neither imported concept is reopened, renamed, overwritten, or approved.
