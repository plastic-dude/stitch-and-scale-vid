## Research decision

CYC’s current abbreviation list defines common terms, notes that special abbreviations may be used, and includes U.S./Canada term differences.[262] W3C’s WCAG 2.2 guidance says the language of passages or phrases should be programmatically determinable, with exceptions including proper names and technical terms, so assistive technology can present mixed-language content appropriately.[263] Stitch & Scale’s contracts keep localization, number/unit context, abbreviations, symbols, charts, captions/audio, export, technical editing, print/chart review, and test knitting separate.[264] [265] These sources support a language-context checklist, but do not prove Stitch & Scale translates or preserves localized meaning.

## Difference from nearest prior angle

The nearest prior angle is `locale-number-format`, which focuses on decimal symbols, grouping, and measurement units. `translation-scope` changes the pain to **whether technical meaning survived a language boundary**. The hook changes to **“Translated is not the same as technically preserved.”** The visual metaphor changes from locale-number fields to **`SOURCE LANGUAGE / TARGET LANGUAGE / TRANSLATED PROSE / ABBREVIATIONS / SYMBOLS / UNITS / SIZE LABELS / LANGUAGE METADATA / TECH REVIEW / STATUS`**. The proof surface changes from localized number/context fields to a current language-context surface. The emotional turn changes from recognizing a numeric locale to making a translation honest about what was translated, what remains technical, and what still needs review. The final line changes to **“Label the language before you trust the shorthand.”**

It is distinct from `spoken-index` because it governs translation and language boundaries rather than spoken semantic order; from `notation-key` because it does not define grouping or notation syntax; from `locale-number-format` because it does not focus on number punctuation; from `export-portability` because it does not focus on file reader behavior; and from imported `false-completion` and `release-gate-roster` because it is not completion or evidence-roster accountability. Neither imported concept is reopened, renamed, overwritten, or approved.
