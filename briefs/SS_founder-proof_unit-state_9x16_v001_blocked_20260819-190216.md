## Concept and distinctness

A numeric value can be visually precise while losing the unit or reference that gives it meaning. The nearest prior angle is `reproducibility-state`, which concerns evidence of a documented rerun. `unit-state` changes the pain to a value losing its unit, scale, or reference basis as it travels through capture and publication. The hook becomes “A number without a unit is unfinished.” The visual metaphor changes from a replay lane to a value card acquiring a unit/reference lock. The proof surface is `VALUE / UNIT / SCALE / REFERENCE / CONVERSION / DISPLAY / ENTERED AS / USED AS`, explicitly illustrative until product proof exists. The emotional turn is from number confusion to measurement clarity. The final line is “Carry the unit with the number.” It does not recreate `quantity-basis`, `conversion-trace`, `measurement-provenance`, `locale-number-format`, `rounding-rule`, `gauge-reality`, `measure-point`, `schematic-scale`, imported `false-completion`, or imported `release-gate-roster`.
