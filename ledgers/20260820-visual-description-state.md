## Continuity decision

`visual-description-state` is a new angle about the scope and form of description attached to an image: purpose, short description, key features, relationships, long description, audio description, caption text, pattern/chart/schematic references, limitations, language, rights, and status. It does not claim that Stitch & Scale automatically creates alt text, long descriptions, audio description, accessible pattern content, WCAG conformance, pattern equivalence, or reader understanding.

## Inherited non-negotiables

David is a developer whose late mother knitted. He does not knit and must not be described as a knitter, knitwear designer, pattern designer, technical editor, or tester. Technical editing, calculation, physical print review, chart readability, schematic scale, care review, and test knitting remain distinct human evidence gates; a description record does not replace any of them.

Captions must not cover cards, text, numbers, logos, controls, or primary actions. Dense descriptions require separate close, readable proof shots. Use one narrator family, caption-on and caption-free review versions, human caption review, full audio listening, and rejection of mixed voices, doubled words, overlaps, room-tone jumps, stale UI, unsupported claims, and duplicate filenames.

Only an original abstract image, fictional description cards, approved founder voice or talking head, consented hand performance, and original or cleared sound may be used. No real chart, schematic, pattern, garment, publication image, customer record, logo, or private data may appear without explicit scoped clearance.

## Proposed description relationship for planning only

`IMAGE D-001` → `PURPOSE` → `SHORT_DESCRIPTION` → `KEY_FEATURES / RELATIONSHIPS` → `LONG_DESCRIPTION` → `AUDIO_DESCRIPTION / CAPTION_TEXT` → `PATTERN_REFERENCE / CHART_REFERENCE / SCHEMATIC_REFERENCE` → `LIMITATIONS / LANGUAGE / RIGHTS_SCOPE` → `REVIEWER / STATUS`.

These are proposed explanatory fields only, not current product labels. A description can convey selected image information but cannot establish pattern correctness, chart equivalence, schematic scale, technical editing, test-knit success, accessibility conformance, or reader understanding. If scope is unknown, keep `IMAGE DESCRIPTION: UNVERIFIED` and do not infer a complete description.
