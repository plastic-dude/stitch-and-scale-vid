## Cross-platform acceptance gates

The final production package would require a destination confirmation, current platform recheck, one narrator family, no mixed voices, no doubled words, no overlaps, stable room tone, original or cleared audio, human-verified captions, caption-on and caption-free review, and a mobile-readable proof sequence. Captions may not cover faces, hands, proof cards, tables, numbers, logos, buttons, menus, rights/contact fields, or primary actions. Dense tables are not permitted as the only proof shot; one artifact family should be shown at readable scale per close shot.

The platform matrix does not establish that the package concept is supported by Stitch & Scale, that any destination would accept the package, that any file is accessible, that a video is compliant, or that a user outcome will follow.
