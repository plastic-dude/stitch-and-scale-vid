## Platform rejection conditions

Reject the cut if captions cover `PROOF`, `VALID_FOR`, `VERSION`, `SIZE`, `GAUGE`, `CONTEXT`, `AUDIENCE`, `TEST_CONDITIONS`, `EXCLUSIONS`, `OUTSIDE_SCOPE`, `REVIEWED`, or `DISPOSITION`; if the card implies universal validity, reliability, grading, fit, gauge calculation, assessment scope, accuracy, or generalizability; if a narrow proof is presented as a universal result; if exclusions or test conditions are hidden; if caption-on and caption-free versions diverge; if auto-captions remain unreviewed; if current platform overlays have not been rechecked; or if mobile crop makes the scope frame or outside-scope boundary unreadable.
