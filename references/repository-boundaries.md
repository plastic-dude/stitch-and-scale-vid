# Repository Boundaries

`plastic-dude/stitch-and-scale-pro` is the application repository. It stores the application-team skill source, Main Worker/Reviewer/Crawler prompts, project evidence, and application documentation.

`plastic-dude/stitch-and-scale-vid` is the public video operations repository. It stores creative briefs, scripts, research, angle and series ledgers, platform matrices, review scorecards, remake orders, manifests, and production prompts.

Full-resolution video files, credentials, refresh tokens, and private user data do not belong in either repository. Full media goes to the configured external archive; manifests bridge the archive and Git.
