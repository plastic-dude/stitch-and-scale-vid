# Pass 97 Browser Findings — Accessibility State

Checked 2026-08-19.

## W3C WCAG 2.2 — Reflow

URL: https://www.w3.org/WAI/WCAG22/Understanding/reflow.html

WCAG 2.2 Reflow explains that content should be presented without loss of information or functionality and without two-dimensional scrolling at a width equivalent to 320 CSS pixels, except for content whose two-dimensional layout is necessary for use or meaning, such as data tables. The guidance also says exceptions are scoped to the relevant section and do not automatically extend to surrounding headings, controls, pagination, or other content.

## W3C WCAG 2.2 — Focus Visible

URL: https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html

WCAG 2.2 Focus Visible requires a keyboard-operable interface to have a mode where the focus indicator is visible and not time-limited. This is a condition-specific interaction check, not proof that every input mode or user context is accessible.

## W3C WCAG 2.2 — Target Size (Minimum)

URL: https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html

WCAG 2.2 Target Size (Minimum) sets a 24 by 24 CSS pixel minimum for pointer targets, with exceptions and spacing alternatives. The guidance explains that target size helps touch users, people with dexterity limitations, one-handed users, and users working in motion. It also says larger targets can still be beneficial even when the minimum is technically met.

## W3C WCAG 2.2 — Captions (Prerecorded)

URL: https://www.w3.org/WAI/WCAG22/Understanding/captions-prerecorded.html

WCAG 2.2 requires captions for prerecorded synchronized media, including dialogue, speaker identification, and meaningful non-speech audio, and states that captions should not obscure relevant information.

## Research implication

A fresh concept may record accessibility checks by condition: surface, user mode, viewport/zoom, input, language, audio/caption state, observed limitation, evidence reference, and status. It must remain blocked until a current product-proof registry or approved capture verifies the exact surface. It must not claim universal accessibility or replace human accessibility review.
