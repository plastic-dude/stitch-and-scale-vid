# Pass 204 Wide Research — Criteria Fit State

**Date:** 2026-08-20  
**Director role:** Planning only; no video generation or upload  
**Research question:** How should an observed result be tested against explicit criteria for a specific intended use without turning a partial check into universal proof?

## Decision changed by research

Pass 203 separated a change event, affected surface, observed result, evidence, and decision. Pass 204 adds the criteria-fit boundary: an observed result needs explicit criteria, a named intended use, and a defined test before anyone can say whether it qualifies. A partial accessibility check, a gauge observation, or a single record review cannot be represented as universal conformance or overall product truth. The fresh angle is `fit-criteria-state`, focused on testing observed evidence against stated requirements for one intended use.

The film will not claim that Stitch & Scale currently evaluates fit, runs acceptance tests, verifies requirements, or certifies accessibility. It will use original neutral cards labeled `ILLUSTRATIVE — NOT PRODUCT UI`.

## Source findings

### 1. NIST validation — objective evidence for a specific intended use

NIST’s glossary defines validation as confirmation through strong, sound, objective evidence that requirements for a specific intended use or application have been fulfilled. It also describes validation as determining whether an object or process is acceptable according to a predefined set of tests and their results. [1]

**Decision impact:** The visual record will show `INTENDED_USE`, `REQUIREMENTS_OR_CRITERIA`, `TEST`, `OBSERVED_RESULT`, and `FIT_STATUS` as separate fields. It will not use a generic `PASS` stamp without naming the use and test.

### 2. GOV.UK user-needs guidance — acceptance criteria and supporting evidence should be recorded

GOV.UK guidance says acceptance criteria can define a user need by listing what must be done for the need to be met. It recommends recording user needs, when the need is met, acceptance criteria, supporting evidence, and rationale. [2]

**Decision impact:** The treatment will keep criteria and evidence visible together, with a named intended task and a pending fit status. A result is not enough if the criteria or supporting evidence are absent.

### 3. W3C Easy Checks — quick checks are not definitive evaluation

W3C’s Easy Checks page says the checks give a rough idea of whether accessibility is addressed and are not a complete evaluation; more assessment by professionals is needed for a definitive and comprehensive evaluation. [3]

**Decision impact:** The script must not claim WCAG conformance or accessibility certification. It will use the source-informed boundary: a quick check can be a limited observation, not a universal accessibility verdict.

### 4. Craft Yarn Council — gauge and actual work are separate evidence

Craft Yarn Council describes gauge as essential to a successful project and recommends a gauge swatch made with the specified yarn, needles, and pattern stitch. It also recommends reading the whole instruction section, doing what the pattern says, and having another person read the pattern aloud when needed. [4]

**Decision impact:** The package will preserve calculation, technical editing, physical print review, chart readability, schematic scale, and test knitting as distinct human evidence gates. An illustrative criteria check cannot replace those checks.

The primary audience remains independent knitwear designers and pattern publishers coordinating calculations, technical editing, physical print review, chart readability, schematic scale, test knitting, samples, swatches, revisions, tester feedback, submissions, and intended users. The planning hypothesis is that a visible result can be overgeneralized when its intended use, criteria, test, and limitations are missing. ## Research limitations

NIST validation terminology is general and domain-specific definitions vary. GOV.UK concerns content and service design, not Stitch & Scale product behavior. W3C Easy Checks explicitly limits quick checks and does not establish a certification result. Craft Yarn Council guidance is industry guidance, not a product contract or measured audience study. The concept is source-informed educational framing only.
