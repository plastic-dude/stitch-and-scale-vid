## Fresh research question

When a knitwear sample uses multiple skeins, what proves the **material and dye-lot identity** attached to the design rather than relying on a generic yarn name, a photograph, or memory?

The question is narrower than `material-trace`, which concerns broader material provenance; `material-availability-state`, which concerns whether a material can be obtained; `substitution-authorization-state`, which concerns permission to use an alternative; and `sample-return-state`, which concerns physical sample custody. Pass 225 focuses on the **lot-level identity of the material used or recorded for a project**, especially when a same-color yarn may come from different dye batches.

## Research synthesis

A generic yarn name or color label is not necessarily a project-level material handoff. Craft Yarn Council asks designers to check ball bands for a same dye lot, keep notes, and submit labels and other distinct project records. [1] [2] Supplier education indicates that different batches can vary, even when the color name is the same, and that exact lots may no longer be obtainable. [3] [4] Those sources support a cautious human record question, not an automatic matching or outcome guarantee.

The film should use two fictional material cards: `YARN NAME / COLOR` and `LOT / LABEL / PROJECT LINK`. The first looks complete; the second reveals the missing lot, fiber/content, quantity, source, sample/design attachment, checked-at time, and observation fields. The end state should remain `MATERIAL LOT: UNVERIFIED` because no current Stitch & Scale material-lot proof is supplied. The story is not that a dye-lot mismatch always ruins a project; it is that a generic name does not establish which material lot was actually used or recorded.

The current seasonal publication context is only a research cue: Knitty’s Winter 2026 submission guidance is current as of June 17, 2026, but it must not be used as urgency, affiliation, or a customer outcome. The category comparison does not support attacking any competitor. It supports a bounded distinction between a physical label or note and a project-linked material record.

## Decision

Select the new angle **`dye-lot-state`**. It is materially distinct from the nearest prior `export-identity-state`, which concerns the identity match between a reviewed file and a released artifact. It is also distinct from `material-trace`, `material-availability-state`, `material-notes`, `substitution-authorization-state`, `sample-return-state`, `care-instruction-state`, `cost-allocation-state`, and the imported blocked concepts.

The proposed hook is: **“Same color is not the same lot.”** The visual metaphor is a fictional yarn card that begins as `COLOR: DUSTY ROSE` and then opens to reveal `LOT: UNKNOWN`, `LABEL: NOT ATTACHED`, and `PROJECT LINK: NOT RECORDED`. The final line is: **“Name the material lot before the sample leaves your memory.”** These are bounded creative lines, not product claims.

The fictional proof surface, if a current product record is later supplied, must distinguish: `MATERIAL M-001 / DESIGN_ID / SAMPLE_ID / MATERIAL_NAME / BRAND_OR_SOURCE / FIBER_OR_CONTENT / COLOR_NAME / COLOR_CODE / LOT_OR_DYE_LOT / LABEL_REFERENCE / QUANTITY / UNIT / ACQUIRED_AT / USED_FROM / SUBSTITUTE_FLAG / OBSERVED_DIFFERENCE / CHECKED_AT / SOURCE_OR_BASIS / REVIEWER / REVIEWED_AT / STATUS`. A recorded lot does not prove color uniformity, fiber performance, gauge, fit, care suitability, or publication acceptance.
