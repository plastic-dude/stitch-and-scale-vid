This is a planning assumption, not a product claim.

## Fresh research question

When a knitwear sample is photographed or shown, what records connect the **garment size, model context, intended fit, and image purpose** without allowing a photo to imply a fit guarantee?

This question is narrower than `fit-intent`, which concerns the meaning of body measurements, finished-garment measurements, ease, and fit notes. It is also distinct from `fit-criteria-state`, `measurement-provenance`, `sample-return-state`, and `publication-boundary-state`. Pass 226 focuses on the **context of the pictured sample**: which size was made, which body/model context is represented, what fit intention the image is meant to show, and what the image does not prove.

## Research synthesis

A photographed garment is not self-explanatory. CYC asks the designer to reconfirm the sample size required to fit the photography model, while its sizing guidance separates body measurements, finished-garment measurements, ease, and schematics. [1] [2] Knitty’s current submission guidance treats model context, intended wear, fit, image quality, and pattern package as connected but distinct decisions. [3] These sources support a narrow record-design question: **what size was made, for which model context, with what intended fit, and for what image purpose?** They do not support claiming that a photograph proves fit, grading accuracy, size inclusivity, or product behavior.

The film should use a fictional image card labeled `PHOTO CONTEXT`, then reveal `GARMENT_SIZE_MADE`, `MODEL_CONTEXT`, `FINISHED_MEASUREMENTS`, `EASE_OR_FIT_INTENT`, and `IMAGE_PURPOSE`. The final state should remain `PHOTO CONTEXT: UNVERIFIED` because no current Stitch & Scale model-context proof is supplied. The story is not that a model is wrong or that a garment fails; it is that an image needs declared context before viewers infer too much.

The seasonal Knitty context is only a research cue. It must not be used as urgency, affiliation, guaranteed publication, or a customer outcome. The category comparison does not support attacking any competitor. It supports a bounded observation that image context, sizing, and fit intent are human records that should not be collapsed into a visual result.

## Decision

Select the new angle **`model-context-state`**. It is materially distinct from the nearest prior `dye-lot-state`, which concerns lot-level physical-material identity. It is distinct from `fit-intent`, which concerns the meaning of sizing numbers; from `fit-criteria-state`, which concerns predefined fit criteria; from `measurement-provenance`, which concerns source of measurements; from `sample-return-state`, which concerns custody; and from `publication-boundary-state`, which concerns transfer or release scope.

The proposed hook is: **“A photo can show the garment and still hide the context.”** The visual metaphor is a fictional `PHOTO CONTEXT` card that opens from a posed garment silhouette to reveal `SIZE MADE`, `MODEL CONTEXT`, `FIT INTENT`, and `IMAGE PURPOSE`. The final line is: **“Name the context before the photo speaks for itself.”** These are bounded creative lines, not product claims.

The fictional proof surface, if a current product record is later supplied, must distinguish: `IMAGE I-001 / DESIGN_ID / SAMPLE_ID / GARMENT_SIZE_MADE / BODY_CONTEXT / MODEL_CONTEXT / FINISHED_MEASUREMENTS / EASE_OR_FIT_INTENT / IMAGE_PURPOSE / POSE_OR_VIEW / CAPTURED_AT / SOURCE_OR_BASIS / RIGHTS_SCOPE / REVIEWER / REVIEWED_AT / STATUS`. A context record does not prove fit, grading, comfort, size inclusion, accessibility, or publication acceptance.
