# Pass 227 wide research: visual-description-state

**Research date:** 2026-08-20 (Africa/Lagos)  
**Director pass:** 227  
**Campaign assumption:** No active human brief was present. This pass assumes founding-tester recruitment through the free demo and early-access cohort remains the campaign objective: an organic, proof-led 9:16 founder short for independent knitwear designers and pattern publishers, with a quiet, specific, craft-respecting tone and no paid placement assumed. This is a planning assumption, not a product claim.

## Fresh research question

When a knitwear pattern image is consumed without reliable visual or audio context, what description preserves the **relevant design information** without pretending to replace the pattern, chart, schematic, technical edit, or human review?

This question is narrower than `model-context-state`, which concerns the context of a pictured sample—size made, model context, fit intention, pose/view, image purpose, and rights scope. Pass 227 focuses on the **description of what an image communicates** and the boundary between a short text alternative, a longer description, spoken visual description, captions, and the underlying pattern or schematic.

## Research synthesis

W3C distinguishes a short text alternative for a simple informative image from a longer description for a complex image, and it explains that audio description can convey actions, scene changes, on-screen text, and other important visual information in synchronized media. [1] [2] [3] Knitty’s current submission guidance adds a craft-specific distinction: atmosphere photos and clear detail photos have different purposes, and relevant design features should be visible so people can follow the pattern. [4] Together, these sources support a bounded record-design question: **what is this image for, what information must be described, and what remains outside the description?**

The film should use a fictional `IMAGE DESCRIPTION` card that first shows `SHORT DESCRIPTION`, then reveals `PURPOSE`, `KEY FEATURES`, `RELATIONSHIPS`, `LONG DESCRIPTION`, and `LIMITATIONS`. A second card keeps `CAPTION`, `AUDIO DESCRIPTION`, `PATTERN`, `CHART`, and `SCHEMATIC` separate. The final state should remain `IMAGE DESCRIPTION: UNVERIFIED` because no current Stitch & Scale description surface is supplied. The story is not that one description method always works; it is that an image needs a declared scope before a short label, caption, or voiceover is mistaken for the full pattern.

The seasonal Knitty context is only a research cue. It must not be used as urgency, affiliation, or publication guarantee. The category comparison does not support attacking any competitor. It supports a bounded observation that image description is purpose-specific and cannot replace pattern text, chart, schematic, technical editing, or test knitting.

## Decision

Select the new angle **`visual-description-state`**. It is materially distinct from the nearest prior `model-context-state`, which concerns the context of a pictured sample. Pass 227 concerns the **scope and form of the description attached to an image**, including whether the image is informative or complex, which features matter, what relationships must be described, and what limitations remain. It is distinct from `caption-state`, `audio-state`, `chart-parity`, `readability-under-load`, `selective-disclosure-state`, `publication-boundary-state`, and the imported blocked concepts.

The proposed hook is: **“A caption is not the whole description.”** The visual metaphor is a fictional `IMAGE DESCRIPTION` card that splits into `SHORT DESCRIPTION`, `PURPOSE`, `KEY FEATURES`, `RELATIONSHIPS`, `LONG DESCRIPTION`, and `LIMITATIONS`, while separate cards keep `CAPTION`, `AUDIO DESCRIPTION`, `PATTERN`, `CHART`, and `SCHEMATIC` visible. The final line is: **“Name what the image needs to say—and what it cannot replace.”** These are bounded creative lines, not product claims.

The fictional proof surface, if a current product record is later supplied, must distinguish: `IMAGE D-001 / DESIGN_ID / IMAGE_ID / PURPOSE / SHORT_DESCRIPTION / KEY_FEATURES / RELATIONSHIPS / LONG_DESCRIPTION / AUDIO_DESCRIPTION / CAPTION_TEXT / PATTERN_REFERENCE / CHART_REFERENCE / SCHEMATIC_REFERENCE / LIMITATIONS / LANGUAGE / SOURCE_OR_BASIS / RIGHTS_SCOPE / REVIEWER / REVIEWED_AT / STATUS`. A description record does not prove pattern correctness, chart equivalence, schematic scale, technical editing, test-knit success, accessibility conformance, or reader understanding.
