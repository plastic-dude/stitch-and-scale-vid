## Spoken-only clean transcript

A correction is not complete until the people using the old version can see what changed. Start with the two states: from this version, to that version. Then name the change: changed, fixed, deprecated, or removed. Where does it land? A row, a chart, a size, a material, a representation? Keep the old state, the new state, and the reason in the same record. If someone must recheck, say that plainly. That is a change notice—not automatically a defect verdict or release approval. I do not want to pretend this paper is the app. Name the change before you ask anyone to trust the new version.
